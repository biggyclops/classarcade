# Selected version: Immersive Gaming

Owner selected concept B. This edition opens the cinematic launcher directly, with the A/B/C review bar and comparison page removed. Existing library, search, filters, favorites, collection creation, settings, import metadata, student/teacher controls and simulated launches remain.

The original three-concept repository is preserved separately. Older design/research documentation describes that exploration; its recommendation is historical rather than the owner's final selection.

Validation: TypeScript and Vite production build; four focused Playwright tests covering direct opening, cinematic world selection/detail/simulated launch, search and persistent favorites, mobile role/settings/keyboard access, desktop/Chromebook overflow and home axe checks. Physical Chromebook and playable educational games remain outside this prototype milestone.
